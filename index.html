CH·02 / SYGNAŁ·LAB

Laboratorium: mała sieć, prawdziwy trening

To nie animacja. W tej sekcji działa minimalna sieć neuronowa (1–H–1, tanh) pisana od zera: forward pass, strata MSE, wsteczna propagacja i SGD — kilkadziesiąt linii TypeScript, zero bibliotek ML. Włącz trening i patrz, jak model dopasowuje się do funkcji celu… albo rozbiegnie, jeśli dasz mu za duży krok uczenia.

AKTYWNY · DZIENNY CI

EV Radar

AGREGATOR OFERT EV · PYTHON · DANE

Problem. Ręczne śledzenie ofert leasingowych i poleasingowych aut elektrycznych w dziewięciu serwisach to praca, której nikt nie powinien wykonywać dwa razy.

Rozwiązanie. Codzienny skan 9 źródeł (publiczne API, __NEXT_DATA__, ng-state, indeks Algolia), deduplikacja po VIN, historia w SQLite — a w efekcie jeden samodzielny plik HTML: nowe oferty, obniżki i zniknięcia, cena na tle mediany rynku oraz szacowana deprecjacja z regresji. Źródła zabraniające skanowania w robots.txt są respektowane — zabezpieczeń nie omijam.

  • Python 3.12
  • mypy strict
  • ruff
  • SQLite
  • Jinja2
  • GitHub Actions
  • pytest
  • Telegram API

OPUBLIKOWANY · PWA OFFLINE

Kalkulator Mierników

NARZĘDZIE EDUKACYJNE · ELEKTROTECHNIKA

Problem. Obliczenia z miernictwa — niepewności pomiarowe, II prawo Kirchhoffa, układy równań — powtarzane ręcznie na każdej lekcji.

Rozwiązanie. Aplikacja webowa bez backendu, która nie tylko liczy, ale pokazuje rozwiązanie krok po kroku: wskazania i błędy przyrządu, systemy liczbowe z pełnym zapisem metody, Kirchhoffa i metodę Cramera. Po instalacji działa offline dzięki service workerowi.

  • PWA

PROTOTYP · W ROZWOJU

MB Translator

APLIKACJA NATYWNA · SWIFT · AI SPEECH

Problem. Rozmowy głosowe PL↔EN bez wchodzenia botom w spotkanie — rozmówca ma po prostu słyszeć naturalny głos z mikrofonu.

Rozwiązanie. Natywna aplikacja menu-bar na macOS (Apple Silicon): mowa → tekst → tłumaczenie → mowa przez Azure Speech i ElevenLabs, klucze API w Keychain, audio przez wirtualne urządzenie. Build odtwarzalny z XcodeGen, testy jednostkowe. Uczciwie: pierwszy kamień milowy (M0) — kompilacja i kolejne etapy w toku.

  • Swift 6
  • macOS 14+
  • AVFoundation
  • Azure Speech
  • ElevenLabs
  • Keychain
  • XcodeGen

CH·05 / PROTOKÓŁ

Jak pracuję

  1. 01

    Kod ponad deklaracje

    Zanim napiszę o umiejętnościach, wrzucam działające repozytorium. Portfolio bez kodu to broszura.

  2. 02

    Mierz, nie zgaduj

    Niepewność pomiaru, mediana rynku, strata w każdej epoce — decyzje na liczbach, nie na wrażeniu.

  3. 03

    Iteruj publicznie

    Prototyp, testy, poprawka, commit. EV Radar ma dziś 9 źródeł, bo kiedyś miał jedno.

  4. 04

    Lokalnie, gdy się da

    Modele lokalne są darmowe i prywatne; API jest wygodniejsze i dokładniejsze. Wybór między nimi to decyzja kosztowa, nie kwestia mody.

  5. 05

    Koszt jest metryką

    Każde wywołanie API ma cenę. Projektowanie pod budżet to część inżynierii, nie dodatek.

  6. 06

    AI to narzędzie pracy

    Agenty kodujące przyspieszają ręce, ale review, testy i odpowiedzialność zostają na mnie.
